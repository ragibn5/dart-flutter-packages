# media_provider_platform_interface

Platform interface for media_provider package.

## Installation

#### From pub.dev

Add this to your `pubspec.yaml`

```yaml
dependencies:
  media_provider_platform_interface: ^1.0.0
```

#### Or, From Git repo

```yaml
dependencies:
  analykit:
    git:
      url: https://github.com/Ragibn5/dart-flutter-packages.git
      path: media_provider/media_provider_platform_interface
      ref: media_provider_platform_interface-1.0.0
```
