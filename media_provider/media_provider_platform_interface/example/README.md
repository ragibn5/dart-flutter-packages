# media_provider_platform_interface example

This package is a platform interface. It only declares the contract that platform implementations fulfil (`MediaProviderPlatform`, `MediaType`, `MediaItem`), so there is nothing to run here.

For a real implementation and a runnable demo, see [media_provider_android] and its [example app][example_app].
