# media_provider

A package to access platform media contents.

## Installation

#### From pub.dev

Add this to your `pubspec.yaml`

```yaml
dependencies:
  media_provider: ^1.0.0
```

#### Or, From Git repo

```yaml
dependencies:
  analykit:
    git:
      url: https://github.com/Ragibn5/dart-flutter-packages.git
      path: media_provider/media_provider
      ref: media_provider-1.0.0
```
